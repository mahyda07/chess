# Chess Game Master
A two-player console-based chess game written in C++.

## Group Members
- Mahida
- Sawera

## How to Play
Run the program:
./chess

## Controls
- Enter moves as: from to
  Example: e2 e4
- Castling: move king two squares
  Example: e1 g1
- Pawn Promotion: automatically prompts when pawn reaches last rank
- En Passant: automatically handled after double pawn advance
- To quit: type quit or q

## Pieces
- K = King
- Q = Queen
- R = Rook
- B = Bishop
- N = Knight
- P = Pawn
- Uppercase = White, Lowercase = Black

## Features
- Full move validation for all pieces
- Check and Checkmate detection
- Stalemate detection
- Castling
- En Passant
- Pawn Promotion
